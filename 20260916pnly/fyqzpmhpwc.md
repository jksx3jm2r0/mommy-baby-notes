# 心疼地抱住胖胖的自己？快醒醒！

> 更新时间：2026-09-16 (UTC+8)

在生殖中心门诊，经常会接诊到一些肥胖的患者，来咨询不孕不育的情况。我们生殖医生一方面希望借助辅助生殖技术帮助她们获得好孕，另一方面也希望能引导她们进行体重的管理，这不仅对于生育有益，对于她们自身的健康与心理、平安顺利的孕期以及孩子的健康也有很大的好处。

**首先，我们要明确怎么样算肥胖？**

**不是“你看我胖了、我觉得你胖了”这么简单。**

根据世界卫生组织(WHO)的规定，肥胖的判定要基于身高体重指数(BMI):BMI=**体重÷身高÷身高**
(一个人身高160cm，体重50kg，BMI=50 ÷ 1.6 ÷ 1.6 ≈19.5)

我国的标准是：

正常：18.5~23.9

过重：25~28

肥胖：>28

**肥胖又有哪些害处呢？**

1. 不孕不育的风险增加,更有可能出现内分泌异常或排卵异常。

2. 妊娠期并发症的风险增加(妊娠期糖尿病、妊娠期高血压、子痫前期、血栓栓塞性疾病等)。

3. 胎儿发育迟缓代谢受损、认知能力低下、神经发育障碍的风险增加。

4. 巨大儿发生率增加，分娩时肩难产、剖宫产、死产的发生率显著增加。

5. 后代发生肥胖及相关疾病(如糖尿病和心血管疾病)的风险增加。

2020年9月，国际妇产科联盟（FIGO）制定了一份**孕前、孕时和产后肥胖的管理指南**，为肥胖的育龄期妇女提供了可靠的指导。

孕前

1. 孕前保健或常规体检，以监测体重值或BMI，可绘制体重变化曲线。鼓励育龄期女性在怀孕前调整好BMI。

2. 建议肥胖女性健康筛查包括肝肾功能、甲状腺功能、血脂水平、糖尿病筛查，其他还可考虑心血管功能检查(如血压、超声心动图)、肺功能检查(如睡眠呼吸暂停相关检查)。

3. 减肥目标一般可定为在6个月内减重5~10%。孕前肥胖管理可采用药物或手术方式，妊娠期不推荐。

4. 围产期补充叶酸，尤其是有神经管缺陷家族史或孕前糖尿病的肥胖女性。

孕时

1. 建议单胎妊娠的肥胖女性将妊娠期增重控制在5~9公斤。

2. 肥胖女性应适当增加蔬菜、水果、全麦、坚果、籽、豆类和海鲜的摄入，减少红肉、加工肉类和油炸食品的摄入。

3. 建议每周至少150分钟的适度体力锻炼。

4. 可向医疗机构寻求肥胖管理的详细指导。

5. 23.9%的妊娠并发症与孕妇超重或肥胖有关。肥胖可能影响胎儿筛查的可靠性，也会增加剖宫产风险。

产后

1. 肥胖女性应在产前和产后进行有关母乳喂养的咨询和指导。

2. 肥胖女性应在产后进行精神健康障碍筛查(如焦虑、抑郁)。

3. 有妊娠并发症(如妊娠期糖尿病、妊娠期高血压、先兆子痫、胎盘早剥、早产和死产等)的女性患心血管疾病的风险较高。

4. 肥胖女性在两次妊娠之间有效减轻体重可以降低再次妊娠发生并发症的风险，增加阴道分娩的机会。

5. 产后选择避孕措施时，应考虑到避孕药与肥胖相关的潜在风险(如血栓栓塞性疾病、体重增加等)。

减肥没有那么容易，每块肉都有它的脾气。但是，控制好孕前体重，才能更好地迎接好孕。
