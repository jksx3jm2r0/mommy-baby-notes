# 火锅汤到底能喝吗？

　　天气越来越冷，热气腾腾的火锅自然是必不可少！吃火锅时，这些事情要当心，吃错了身体可要遭罪。特别是第一条，不少人就正在做。

升血脂、痛风、致癌，

你还敢喝火锅汤吗？

　　火锅汤无论是白汤还是辣汤，都是高汤为底料熬制的。而高汤中油脂含量高，所以才呈现出乳白色。那都是小颗粒的油脂，喝下去等于喝了小半碗的油，对消化系统造成负担，而且会让人发胖，**血脂升高**。

　　还有就是火锅汤中嘌呤含量非常高，嘌呤会引起尿酸高，导致**痛风、关节痛**。

　　火锅煮的时间越久，汤中的亚硝酸盐、亚硝胺类致癌物含量升高，长期食用会导致慢性中毒而诱发**消化系统癌变**。

　　再者就是，由于不断蒸发水分浓缩，汤中的钠、钾、磷离子含量非常高，会导致**人血管病变，心脏和肾脏功能失调**。

　　如果还有人喜欢趁热喝汤，更容易烫伤食道，患上**口腔溃疡和食道癌**。

吃火锅绝对不能做哪些事？

　　首先就是**不能趁热吃**，太热的食物会烫伤食道，容易患上口腔溃疡和食道癌，一定要等凉了再吃。

　　吃火锅的时候要**使用公筷**，避免交叉感染（幽门螺杆菌耐高温，很容易互相传播）。

　　吃火锅的**肉、菜类要充分烫熟**再吃，避免微生物和寄生虫的感染。

　　本身有胃病和消化系统疾病的，**不要吃过辣的火锅**。

　　吃辣火锅的时候**不要喝高度数白酒**，白酒会损伤胃黏液层，再加上辣椒和热食的刺激，很容易引起胃出血。

　　吃火锅同时和之后，不要立即吃**过冷的冷饮和甜点**，容易造成胃痉挛。

怎样健康吃火锅？

　　最好是吃**清汤锅**，少油，自己制作食材保证新鲜健康。

　　食物应该要**冷了再吃**。

　　涮火锅的顺序应该是**先吃点主食和蔬菜保护胃，之后再吃肉类**，以避免食用过多的肉和海鲜。 而且这样，蔬菜和主食也不会吸收太多的高嘌呤高油脂的火锅汤。

　　不要喝火锅汤，**不要使用剩下的汤继续煮菜**。 

　　不要和高度数白酒同食，**要喝酒就喝常温的啤酒**。

　　一顿火锅之后，**下一餐一定要清淡一点，多吃粗粮、豆类、蔬菜**，补充膳食纤维和维生素，以利于预防消化系统癌症。
